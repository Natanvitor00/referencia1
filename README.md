# Bravo Construções

Site demonstrativo migrado para Next.js com JavaScript e React.

## Executar localmente

1. Instale o Node.js (versão 20.9 ou superior).
2. No terminal, entre nesta pasta e instale as dependências:

   ```bash
   npm install
   ```

3. Inicie o servidor de desenvolvimento:

   ```bash
   npm run dev
   ```

4. Acesse [http://localhost:3000](http://localhost:3000).

O formulário abre uma conversa no WhatsApp com os dados do orçamento. Os dados e depoimentos do site são demonstrativos.
